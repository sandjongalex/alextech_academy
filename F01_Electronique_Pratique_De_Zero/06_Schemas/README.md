# 06 — Schémas

Ce dossier centralise les schémas électroniques et synoptiques de F01.

À classer par module ou projet :
- LED + résistance ;
- série / parallèle ;
- diviseur de tension ;
- RC ;
- redressement ;
- BJT ;
- MOSFET ;
- relais + diode flyback ;
- optocoupleur ;
- AOP ;
- Buck 12 V → 5 V ;
- projet final de contrôle de température.

Chaque schéma doit être clairement nommé, versionné et lié au cours/TP correspondant.
