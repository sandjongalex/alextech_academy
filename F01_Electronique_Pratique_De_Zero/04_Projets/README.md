# 04 — Projets

Ce dossier regroupe les mini-projets et le projet final.

## Mini-projets

- Commande d’un relais avec diode de protection.
- Petite alimentation DC redressée et filtrée.
- Commande d’une charge par transistor BJT.
- Commande PWM d’un moteur DC par MOSFET.
- Interface microcontrôleur → optocoupleur → transistor → relais.
- Amplification et conditionnement d’un signal de capteur.
- Convertisseur Buck 12 V → 5 V.

## Projet final

### Contrôleur intelligent de température

Éléments principaux :
- capteur ;
- comparateur ou conditionnement ;
- transistor ou MOSFET ;
- ventilateur ;
- relais ;
- LEDs ;
- alimentation ;
- protections.

Objectif : terminer F01 sur un système complet et préparer la transition vers Arduino, ATmega328P et STM32.
