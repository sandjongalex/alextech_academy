# TP Module 1 — Mesures de base au multimètre

## Objectif
Apprendre à utiliser correctement un multimètre numérique pour les mesures élémentaires.

## Matériel
- 1 multimètre numérique
- 1 pile 1,5 V ou 9 V
- quelques résistances
- fils de connexion
- breadboard
- petit montage basse tension pour la mesure de courant

## Partie A — Mesure de tension continue
1. Régler le multimètre sur VDC.
2. Brancher le cordon noir sur COM et le rouge sur V/Ω.
3. Mesurer la tension de la pile.
4. Inverser les pointes de touche et observer le signe.
5. Noter la valeur mesurée.

## Partie B — Mesure de résistance
1. Déconnecter toute alimentation.
2. Régler le multimètre sur Ω.
3. Mesurer plusieurs résistances.
4. Comparer valeur nominale et valeur mesurée.

## Partie C — Test de continuité
1. Régler le multimètre en mode continuité.
2. Tester un fil intact.
3. Tester un circuit ouvert.
4. Observer le bip et l’affichage.

## Partie D — Mesure de courant
1. Utiliser uniquement un montage basse tension préparé pour le TP.
2. Déplacer le cordon rouge vers l’entrée courant appropriée si nécessaire.
3. Ouvrir le circuit.
4. Insérer le multimètre **en série**.
5. Mesurer le courant.
6. Replacer ensuite le cordon rouge sur l’entrée V/Ω.

## Erreurs à éviter
- mesurer une résistance sur un circuit alimenté ;
- placer le multimètre en mode courant directement aux bornes d’une source ;
- utiliser la mauvaise borne de courant ;
- oublier de revenir sur l’entrée V/Ω après une mesure de courant.

## Compte rendu
L’apprenant doit fournir un tableau avec : grandeur, calibre/mode, valeur attendue, valeur mesurée, observation.

## Validation
Le TP est validé si l’apprenant sait expliquer pourquoi une tension se mesure en parallèle et un courant en série.
