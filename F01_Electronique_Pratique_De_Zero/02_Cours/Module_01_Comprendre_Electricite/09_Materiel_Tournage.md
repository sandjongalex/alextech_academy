# Matériel de tournage — Module 1

## Électronique
- multimètre numérique ;
- piles 1,5 V et/ou 9 V ;
- alimentation de laboratoire basse tension ;
- résistances variées ;
- breadboard ;
- fils Dupont ;
- LED + résistance adaptée ;
- interrupteur ou bouton poussoir ;
- petite lampe ou charge basse tension ;
- deux sources isolées pour la démonstration GND.

## Tournage
- caméra ou smartphone ;
- trépied ;
- support vue du dessus ;
- micro-cravate ou micro USB ;
- éclairage principal + éclairage de table ;
- fond propre ;
- tableau blanc ou tablette pour annotations.

## Captures complémentaires
- gros plan sur l’écran du multimètre ;
- plan de dessus sur breadboard ;
- capture écran des animations/schémas ;
- plan face formateur pour les introductions et résumés.
