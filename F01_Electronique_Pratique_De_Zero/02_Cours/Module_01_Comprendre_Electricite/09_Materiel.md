# Module 1 — Matériel nécessaire

## Matériel minimum

- 1 multimètre numérique ;
- 1 pile 1,5 V ou 9 V ;
- 1 porte-pile si nécessaire ;
- quelques résistances de valeurs différentes ;
- fils de connexion ;
- breadboard facultative.

## Matériel recommandé pour démonstration vidéo

- alimentation de laboratoire ;
- deuxième multimètre pour comparer deux grandeurs ;
- petite lampe ou LED avec résistance adaptée ;
- charge USB ou petit module basse tension ;
- quelques câbles volontairement coupés pour les tests de continuité.

## Sécurité

Pour ce module d'introduction, les manipulations pratiques doivent rester en basse tension continue. Les exemples secteur peuvent être expliqués visuellement ou théoriquement sans demander au débutant d'effectuer des mesures sur le réseau électrique domestique.
